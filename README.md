# Re: BiliLiveNotification
## Re：B站直播开播提醒
[Windows](https://github.com/SadYuyuko/biliLiveNotification/releases/download/v1.3/Re.BiliLiveNotification.exe) | [Android](https://github.com/SadYuyuko/biliLiveNotification/releases/download/Android_1.0/Re.BLN_Android_1.0.apk) 下载  

修改内容：  
 - 开机自启
 - 自动开始检测  
 - 自动跳转浏览器  
 - 适配高分屏  
 - 删除启动通知，因为系统推送会留下一长串通知记录...  
 - 将`.ini`配置文件存放至`C:\Users\用户名\.ReBiliLiveNotification\ReBLN.ini`  
 - 自定义API（好像用不到...）  
 - kotlin移植Android版：直接跳转B站APP直播间  

注意：  
1.设置开机自启需要以管理员运行，移动.exe位置后要重新设置开机自启  
2.输入房间号后要重新开始检测或保存设置才会加入检测  
3.直播通知弹窗默认10分钟未点击自动关闭
