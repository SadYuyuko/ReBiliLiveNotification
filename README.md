# Re: BiliLiveNotification
## Re：B站直播开播提醒
[exe单文件](https://github.com/SadYuyuko/biliLiveNotification/releases/download/v1.1/Re.BiliLiveNotification.exe)  

修改内容：  
 - 使用计划任务开机自启  
 - 自动跳转浏览器  
 - 自动开始检测  
 - 单实例启动  
 - 删除二级菜单，直播间列表上下滑动  
 - 删除启动通知，因为系统原生推送会留下一长串通知记录...  
 - 将.ini配置文件存放至`C:\Users\用户名\.ReBiliLiveNotification\ReBLN.ini`  
 - 自定义API（好像用不到...）  
  
注意：  
1.设置开机自启需要以管理员运行，移动.exe位置后要重新设置开机自启  
2.输入房间号后要保存设置才会加入检测  
3.直播通知弹窗默认10分钟后未点击自动关闭
